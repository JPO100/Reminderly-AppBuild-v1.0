# Design standards

One document per standard. Each rule lives in exactly one document; nothing is restated elsewhere. Owned and updated in Reminderly, shared with other NeatlyMade apps by copying a document unchanged. Each document carries a version and a change log so another app can tell when its copy is stale.

| Document | Covers | Status |
|----------|--------|--------|
| [overlay-standards.md](./overlay-standards.md) | Centred overlays: two-zone principle, geometry, spacing, buttons, scrolling, toggles, accessibility, tutorials, screen sizes, checklist; Reminderly appendix | v1.0, 2026-11-03 |

Everything else (colours, typography, spacing and sizing, panels, bottom sheets, motion) is still in [../design.md](../design.md) and moves here, one document at a time, when it is rewritten as a standard.
